# Agile (Scrum + Kanban)

Placeholder for the Agile screens. Each sub-folder gets the same layout as the
other features (`components/`, `hooks/`, `types.ts`) once its screens are built:

- `backlog/` – product backlog, ordering, refinement
- `board/` – Scrum and Kanban boards, WIP limits, swimlanes
- `sprints/` – sprint planning, start and complete
- `releases/` – release planning and versions
- `reports/` – burndown, burnup, velocity, cumulative flow
- `workflow/` – per-project workflow statuses and transitions

Estimation (story points or hours) is a per-project setting.
