# Bright PMO (V2)

Project and portfolio management for construction and engineering work:
EPS, portfolios, projects, WBS and scheduling, resources, risks, budget,
procurement, documents, timesheets and approvals. V2 adds Agile (Scrum and
Kanban) and Hybrid projects alongside Waterfall, and multiple organisations.

## Repository layout

| Folder | What it is | Port |
|---|---|---|
| `PMO-Client/` | The frontend. Next.js 15, React 18, Tailwind v4. A pure frontend, not connected to any backend yet: screens show empty states and actions report "not connected". The integration with the new backend starts from here. | 7060 |
| `PMO-Soul-Backend/` | The backend: NestJS 11 + Prisma, generated by Soul from `docs/target-schema.prisma`. Runs locally on its own database. See its README. | 7062 |
| `PMO-Soul-Admin-Panel/` | Soul's generated admin panel: platform administration (tenants, users, roles, workflows) against the backend. See its README. | 7063 |
| `migration/` | Scripts that copy the legacy database into the backend's database. Self-contained. See its README. | |
| `docs/` | The target schema, conventions and integration notes. | |

The old backend (`PMO-Legacy-API`, a Next.js API app) is no longer on this
branch. It is on the `dev` branch, as a reference for business logic still to
rebuild (approvals, critical path, closure checks). Its database stays: the
migration reads it.

## Running locally

Requirements: Node.js 20+ and a local PostgreSQL server.

1. **Environment.** In each app folder, copy `.env.example` to `.env` and fill
   it in.
2. **Install** in each app folder: `npm install`. npm 11 no longer runs
   packages' install scripts unless they are approved, so run the Prisma
   generate step each README lists.
3. **Start** each app in its own terminal:

   ```
   cd PMO-Soul-Backend     && npm run start:dev   # http://localhost:7062
   cd PMO-Soul-Admin-Panel && npm run dev         # http://localhost:7063
   cd PMO-Client           && npm run dev         # http://localhost:7060
   ```

   First-time backend set-up (database, tables, seed) is in
   `PMO-Soul-Backend/README.md` ("Running locally").

## Checks before committing

In each app you changed:

```
npm run typecheck     # PMO-Client; must report 0 errors
npm run lint          # PMO-Client; must report 0 errors
```
